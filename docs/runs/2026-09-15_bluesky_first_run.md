## 分かったこと

1. **searchPosts は書いた語を全部含む投稿しか返さない。** 3語以上はほぼ0件
   （「web制作 断られた」0件、「サイトリニューアル どこに頼む」0件）
2. **日本語の語の切り方が甘い。** 「ホームページ 作りたい」で和菓子の告知が返り、
   「LP 作りたい」はURLの `lP9FBgS8nJs` に当たる。1語が広いと（サイト／web制作）
   レシピサイト・同人サイト・個人サイトの話で埋まる
3. **サンプル20件の内訳：頼む側0件／売り手・同業6件／無関係14件。**
   買う側に近いのは「日本テニス協会のサイトがリニューアルしてる」程度で、発注の話ではない
4. YouTube（4件）と合わせても、web-seisaku の「お客さんの声」は週次で成立する量がない
